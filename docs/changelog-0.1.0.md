## Better AE2 0.1.0

Initial public release for Forge 1.20.1 and NeoForge 1.21.1.

- Searchable AE2 network sidebar on supported inventory/container screens.
- One-click deposits, item withdrawals, and separate player/container Shift-click controls.
- Wireless-terminal protection; main inventory deposits leave the hotbar untouched.
- Native AE2 terminal availability checks, including compatible wireless terminal implementations.
- Sidebar refreshes when a terminal is removed or put back without reopening the screen.
- Vanilla recessed slot rendering, configurable position, and sidebar visibility settings.
- Curios accessory-slot support is optional; JEI integration is optional.

Requires Applied Energistics 2. Install on both client and server.
